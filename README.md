## Controles y atajos del teclado

Doble click para crear o editar nota.

Mover notas manteniendo el click encima.

Click derecho para ver el menú contextual.

Click y arrastrar para empezar una selección.

Seleccionar notas discretamente con Crtl+click.

Seleccionar todo con Ctrl+A.

Borrar selección con Delete o Supr.

Deshacer acción con Ctrl+Z.

Rehacer acción con Ctrl+Y.

Duplicar selección pulsando D.

Fusionar selección pulsando F.

Unir o separa dos notas seleccionadas pulsando espacio.

Guardar esquema en formato JSON con Ctrl+S.

Cargar esquema guardado en JSON con Ctrl+O.

Guardar esquema en imagen PNG con Ctrl+P, con opción de fondo trasparente.

Alternar tema claro / oscuro con el menú contextual.
